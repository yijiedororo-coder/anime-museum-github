# 日本动漫作品库

来源为用户提供的欧乐影院「动漫 / 日本 / 全部年份 / 全部类型 / 最新」分类：

https://www.olevod.com/nav/%E5%8A%A8%E6%BC%AB/%E6%97%A5%E6%9C%AC/%E5%85%A8%E9%83%A8%E5%B9%B4%E4%BB%BD/%E5%85%A8%E9%83%A8%E7%B1%BB%E5%9E%8B/%E5%85%A8%E9%83%A8/%E5%85%A8%E9%83%A8/%E6%9C%80%E6%96%B0.html

在 2026-10-05 逐页读取了全部 30 页、1,431 条列表记录，并滚动每页以加载和核对全部封面。以完整作品名称合并同名记录，得到 1,427 个独立作品框。各季名称不同的记录分别保留。

- `olevod-catalog.json` 保存完整来源记录、来源页码、原始封面 URL、提取时间及合并后的作品。
- `catalog-data.js` 是网页使用的资料快照。修改后需同步生成此文件。
- `alternateRecords` 保留被合并的同名来源记录，其封面也可从该作品的「插画画集」打开。
- 封面缓存保存在 `assets/olevod/`；原始 URL 同时保留在资料中。
- 年份、配音、更新状态和评分照来源站标注整理，未额外核实；年份 0 在界面显示为「年份未标注」。
- 列表简介只给出很短的截取文字，存于 `summary`，不在网页中当作完整简介展示。

每部真实作品有四个子文件夹。插画画集保存来源封面，世界与故事提供可下载的作品资料；周边收藏与角色档案准备为空文件夹，等待加入用户素材。原来的十个原创示例仍可从作品库选择菜单打开。

画布为每部真实作品安排一个固定位置；只绘制视野附近的框。立体书架同样按视野加载，封面目录每次增加 60 部。搜索会检索完整作品库。

成功标志：打开作品库后，选择「日本动漫作品库」，页面显示「1427 个 IP」；搜索「海贼王」可进入其档案，打开「插画画集」查看封面，或打开「世界与故事」下载作品资料。
